# دمج الورديات في الواجهة الأصلية

النسخة الأساسية: OASSystem_MultiCurrency_OriginalUI_Full.zip.
لا توجد Migration جديدة. لا تتغير قواعد الترحيل أو بنية قاعدة البيانات في هذه الدفعة.

- صفحة الورديات تستخدم AccountingWorkspaceHost فقط.
- يختار محرر الوردية الصندوق التشغيلي، ثم يحمل كل العملات النشطة والأرصدة الدفترية؛ الإدخال الفعلي إجباري لكل عملة وسبب فرق الافتتاح مطلوب عند وجود فرق.
- الفتح والإغلاق والاعتماد تستدعي عمليات المجموعات الموجودة في الخادم. تفاصيل الحركة والتسوية لكل عملة تعرض داخل محرر الوردية نفسه؛ الورديات التاريخية المنفردة تبقى قابلة للعرض والإدارة.
- قائمة الورديات تجمع سجلات العملات قبل تقسيم الصفحات في العميل، باستخدام طلبات الصفحات الحالية. لا تجمع المبالغ متعددة العملات حسابياً.
- فلتر الصندوق في التقرير يستخدم UiReportSearchPicker مثل بقية الفلاتر.

## عند تطبيق ZIP الملفات المعدلة فقط
انسخ الملفات فوق النسخة الأساسية. احذف الملفات التالية اختيارياً (غير مستخدمة بعد التعديل، وحذفها تم بالفعل في ZIP الكامل):

- `OAS.Client/Accounting/Components/CashBoxesPanel.razor`
- `OAS.Client/Accounting/Components/CashBoxesPanel.razor.css`
- `OAS.Client/Accounting/Components/CashBoxShiftsPanel.razor`
- `OAS.Client/Accounting/Components/CashBoxShiftsPanel.razor.css`

## التحقق المطلوب في بيئة التطوير
Clean Solution ثم Rebuild Solution. اختبر فتح وردية لصندوق بثلاث عملات، منع وردية ثانية، منع فتحها عند نقص الجرد، إغلاق كل العملات واعتمادها، تسوية فرق مستقل، عرض الحركات والتقارير، وإغلاق وردية تاريخية منفردة. اختبر البحث والترقيم. لا يوجد SDK أو SQL Server في بيئة إعداد الحزمة؛ لم يجر البناء أو التشغيل الفعلي. قائمة الورديات تعتمد تحميل كل صفحات البيانات قبل التجميع، وقد تحتاج مستقبلاً إلى استعلام مجمع من الخادم للبيانات الكبيرة.
