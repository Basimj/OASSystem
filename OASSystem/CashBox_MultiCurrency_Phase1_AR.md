# تعدد عملات الصندوق — المرحلة الأولى

الأساس: OASSystem_CashMovement_ConfigurationFix_Full.zip.

## التطبيق
خذ نسخة احتياطية من قاعدة البيانات، وأغلق الورديات النشطة قبل بدء إضافة العملات. استبدل الملفات، ثم نفذ Clean Solution وRebuild Solution، ثم من Package Manager Console نفذ:

```powershell
Update-Database -Project OAS.Infrastructure -StartupProject OAS.API
```

Migration: `20261128193000_AddOperationalCashBoxes`.

تنشئ Migration صندوقًا تشغيليًا لكل حساب نقدي سابق بالمعرف نفسه. لا تجمع الحسابات القديمة تلقائيًا ولا تعدل معرّفات الحسابات النقدية أو حركاتها. اختبر الترحيل أولًا في نسخة تطوير. الرجوع عن الترحيل ممنوع عند وجود صندوق يجمع عدة حسابات عملات.

## الاستخدام
1. افتح الصناديق والخزائن، ثم إضافة.
2. اترك اختيار الصندوق الموجود فارغًا لإنشاء صندوق جديد بعملته الأولى. لإضافة عملة أخرى افتح إضافة واختر الصندوق الموجود.
3. أدخل اسم حساب العملة وحدد العملة ونوع الحركة والحالة. ينشأ حساب محاسبي مستقل. لا تتكرر العملة في المجموعة نفسها.
4. اختبر القبض والصرف بعملتين مختلفتين، وحاول إضافة عملة مكررة أو إضافة عملة أثناء وردية نشطة.

## الحدود
هذه مرحلة تأسيس وليست التنفيذ النهائي. يبقى جدول العرض قائمًا على حسابات العملات، ويعرض اسم الصندوق التشغيلي. تبقى الورديات منفصلة لكل عملة، ولا يوجد فتح/إغلاق موحد أو جرد مجمع بعد. حالة النشاط وإعداد اشتراط الوردية ما زالا على حساب العملة (ينسخ إعداد الوردية عند الإلحاق). لا توجد إعادة تجميع للحسابات التاريخية ولا تعديل لتقارير الصناديق أو Excel بعد. أسماء الصناديق التشغيلية تتبع اسم حساب العملة الأول عند تعديله. لم تُنفذ اختبارات تشغيل أو بناء أو SQL Server هنا لعدم توفر .NET SDK وبيئة SQL Server. توجد اختبارات NUnit جديدة يجب تشغيلها محليًا.
