# تكامل OAS Print — النسخة الاحترافية

أضيف إلى الحل مشروعان مستقلان عن المتصفح:

- `OAS.Printing.Core`: نماذج القوالب، تعريف الحقول، وقراءة بيانات JSON.
- `OAS.Print.Desktop`: تطبيق WPF مستقل ينشر باسم `OAS.Print.exe` ويحتوي مركز الطباعة ومصمم القوالب.

## مسار الطباعة

1. افتح سند قبض أو سند صرف محفوظًا داخل OAS.
2. يظهر زر **طباعة** في شريط الإجراءات بجوار أوامر السند.
3. يرسل Client إلى `POST /api/printing/jobs` نوع السند ومعرّفه وخيارات المهمة فقط.
4. يعيد API قراءة السند المحفوظ من قاعدة البيانات ويكوّن Print Payload موثوقًا.
5. توضع المهمة في Queue لمحطة الطباعة المطلوبة (`DEFAULT` افتراضيًا).
6. يسحب `OAS.Print.exe` المهمة من `GET /api/printing/desktop/jobs/next`.
7. يختار البرنامج القالب الافتراضي لنوع المستند والطابعة المخصصة له.
8. تظهر البيانات الحقيقية للمهمة داخل المصمم، وتسجل المهمة في **سجل الطباعة** ثم تطبع عبر Windows Print Queue.
9. لا يستخدم النظام `window.print()` أو طباعة المتصفح.

## واجهة OAS Print

البرنامج يحتوي على تنقل جانبي وصفحات مستقلة:

- الرئيسية: حالة الاتصال، القوالب، الطابعات، وملخص مهام الجلسة.
- القوالب: إدارة القوالب وإنشاء/نسخ/حذف/معاينة القالب.
- مصمم القوالب: تحريك العناصر، خصائص النصوص والحقول والجداول والصور والأشكال، Zoom واحتواء الورقة.
- سجل الطباعة: آخر مهام الجلسة وحالتها والطابعة المستخدمة.
- الطابعات: عرض طابعات Windows وتحديد الافتراضية.
- الإعدادات: API، محطة العمل، المستخدم، API Key، فترة الفحص والطابعة المخصصة لكل نوع مستند.

الشريط العلوي يعرض اسم النظام، حالة الاتصال، التاريخ، الوقت، والمستخدم. عند وصول مهمة من OAS يعرض آخر مستخدم أنشأ طلب الطباعة.

## تشغيل النظام والطباعة أثناء التطوير

الإعداد الافتراضي:

- API: `https://localhost:7245`
- Workstation: `DEFAULT`
- Polling: مفعّل

من Visual Studio يمكن استخدام **Multiple startup projects** وتشغيل:

- `OAS.API`
- مشروع الواجهة الرئيسي حسب إعداد الحل
- `OAS.Print.Desktop`

إذا تغير منفذ API افتح صفحة **الإعدادات** في OAS Print وعدل `API Base URL`.

## القوالب الجاهزة

- سند قبض احترافي A4 أفقي: `ACC-RECEIPT-A4-PRO`
- سند صرف احترافي A4 أفقي: `ACC-PAYMENT-A4-PRO`
- مصروف A5
- قيد يومية A4

قالبا القبض والصرف يحتويان على:

- بيانات المنشأة وهوية OAS.
- رقم/تاريخ/حالة السند.
- المبلغ الأساسي والعملة في حقول منفصلة؛ لا يلصق كود العملة بالمبلغ.
- جدول تفصيلي للأطراف وطرق الدفع والصندوق/البنك والعملات وسعر الصرف والمبلغ الأساسي والمرجع والبيان.
- ملخص العملات.
- المبلغ كتابة.
- التوقيعات ووقت الطباعة.

القوالب المدمجة تحمل رقم إصدار. عند تحديث إصدار قالب OAS المدمج يقوم البرنامج بترقية النسخة القديمة لنفس القالب في `%LocalAppData%\OAS\Print\Templates`، بينما القوالب المخصصة بمعرفات مختلفة لا يتم استبدالها.

## بيانات المنشأة في رأس السند

تقرأ من `OAS.API/appsettings.json`:

```json
"Application": {
  "Name": "OAS SYSTEM",
  "Address": "",
  "Phone": "",
  "CommercialRegistration": "",
  "TaxNumber": ""
}
```

ضع بيانات المنشأة الفعلية ليظهر رأس السند تلقائيًا في الطباعة.

## الطابعات المخصصة

من صفحة **الإعدادات** في OAS Print يمكن تحديد:

- طابعة افتراضية عامة.
- طابعة خاصة لـ `ReceiptVoucher`.
- طابعة خاصة لـ `PaymentVoucher`.

الأولوية عند تنفيذ المهمة هي:

1. الطابعة المرسلة مع المهمة إن وجدت.
2. طابعة نوع المستند.
3. الطابعة الافتراضية.
4. الطابعة المحددة حاليًا في المصمم.

## API Key

في `OAS.API/appsettings.json`:

```json
"Printing": {
  "DesktopApiKey": ""
}
```

القيمة الفارغة مناسبة للتطوير المحلي. عند النشر ضع قيمة سرية وأدخل القيمة نفسها في إعدادات `OAS.Print.exe`.

## إخراج EXE

### Framework-dependent

لا يحتاج تنزيل Runtime Pack أثناء كل Build، لكنه يحتاج `.NET 9 Desktop Runtime` مثبتًا على الجهاز:

```bat
scripts\publish-oas-print-win-x64-framework-dependent.cmd
```

الناتج:

```text
publish\OAS.Print\framework-dependent\OAS.Print.exe
```

### Self-contained / EXE مستقل

```bat
scripts\publish-oas-print-win-x64.cmd
```

الناتج:

```text
publish\OAS.Print\win-x64\OAS.Print.exe
```

أول نشر Self-contained قد يحتاج الوصول إلى NuGet لتنزيل Windows Runtime Pack إذا لم يكن موجودًا في كاش الجهاز.

## Queue

Queue الحالية داخل ذاكرة الـAPI ومناسبة للطباعة الفورية. إذا أعيد تشغيل السيرفر قبل استلام المهمة فلن تبقى المهمة. يمكن لاحقًا تحويل Print Jobs إلى جدول دائم في قاعدة البيانات دون تغيير عقد برنامج الطباعة.
