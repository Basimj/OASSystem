# واجهة كشف الحساب المطابقة للمرجع - تنفيذ أولي

## المسارات
- `/ui-lab/reports/account-statement`: عرض مكون التقارير بالبيانات التجريبية المرجعية.
- `/accounting/reports/account-statement`: كشف الحساب الفعلي من خدمة دفتر الأستاذ.
- `/accounting/reports`: رابط «كشف حساب» الجديد بجانب أدوات التقارير القديمة.

## المكون العام
`Shared/UiLib/Components/Reports/UiReportWorkspace.razor` مع `UiReportMetric.razor` وملف CSS مستقل. يحتوي Slots: Toolbar, QuickFilters, FilterPanel, TableContent, Pagination, Metrics. يمكن استخدامه في تقارير أخرى دون نسخ الهيكل.

## المعلومات المحاسبية
تعتمد الصفحة الحقيقية على `GetGeneralLedgerAsync` الحالي، وتعرض القيود المرحّلة حصراً. عرض القيم بالعملة الأساسية. **تصفية الفرع ومركز التكلفة وتغيير العملة معطلة عن عمد** لأن واجهة API الحالية لا توفر مرشحاتها؛ يتطلب تفعيلها تحديث الخدمات واستعلامات قاعدة البيانات. كذلك لا توجد قيمة محاسبية موحدة للخصومات في DTO دفتر الأستاذ، لذا تعرض البطاقة «غير متاح» بدل اختلاق قيمة صفر. أرقام المستند في الرد الحالي هي رقم القيد، وأرقام المراجع تعتمد `Reference` المتاح.

## المخرجات والاختبار
- قائمة الصفحات: 10/25/50/100، البحث الفوري داخل النتائج المحملة، زر تطبيق/تحديث الفلاتر، لوحة جانبية قابلة للفتح والطي.
- التصدير الحالي CSV بترميز UTF-8 يمكن فتحه في Excel؛ زر PDF يستخدم واجهة الطباعة للمتصفح لحفظ PDF ولا ينشئ PDF مستقلًا على الخادم.
- الطباعة تخفي الفلاتر وأزرار الإجراءات وفق CSS.
- لا تحتوي بيئة العمل على .NET SDK؛ لم يمكن إجراء `dotnet build` أو اختبار العرض الحقيقي في المتصفح. يُرجى البناء والتحقق بصريًا على المشروع الأصلي قبل الإنتاج.
- لا تتوافر بايتات النسخة الأحدث من المكتبة في بيئة الملفات الحالية؛ بُني التعديل على `OASSystem.zip` المرفق دون تعديل ملفات تقارير المبيعات، ويجب دمجها فوق نسخة المكتبة الأحدث للمحافظة على جميع تحسيناتها.
