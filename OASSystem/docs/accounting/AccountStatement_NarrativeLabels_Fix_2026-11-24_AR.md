# إصلاح أوصاف كشف الحساب التقنية

تم تعديل `ResolveLedgerDescription` في خدمة التقارير المحاسبية لاستبدال التسميات التقنية المعروفة ببيانات عربية مفهومة دون تعديل القيود المحاسبية المسجلة.

| النص المصدر | نص العرض |
|---|---|
| `COGS / INV-... / line 2` | تكلفة البضاعة المباعة — فاتورة رقم ... — البند 2 |
| `OGS / INV-... / line 2` | نفس المعالجة (لتغطية صيغة النص المذكورة) |
| `COGS reversal / SR-... / line 1` | عكس تكلفة البضاعة المباعة — مرتجع مبيعات رقم ... — البند 1 |
| `Customer return / SR-...` | تخفيض ذمم العملاء — مرتجع مبيعات رقم ... |
| `Sales revenue reversal / SR-...` | عكس إيرادات مبيعات — مرتجع رقم ... |
| `Sales tax reversal / SR-...` | عكس ضريبة المبيعات — مرتجع رقم ... |
| `Sales tax / INV-...` | ضريبة مبيعات — فاتورة رقم ... |

التحويل يحدث عند توفر رقم المستند الأصلي من `ResolveLedgerDocumentsAsync` فقط. النصوص غير المعروفة تُترك كما هي حمايةً للمضمون المحاسبي.

## التحقق المطلوب

- إعادة بناء الخدمة وتشغيل كشف الحساب على قاعدة البيانات.
- اختبار فواتير المبيعات ومرتجعاتها، بما فيها أكثر من بند.
- التأكد أن البحث والطباعة والتصدير تعرض النصوص المحسنة.
- فحص الأوصاف غير المعروفة لتطوير القاموس لاحقًا.

لم يُنفذ `dotnet build` في بيئة إعداد الأرشيف.
