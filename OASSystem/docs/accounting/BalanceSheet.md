# الميزانية العمومية / Balance sheet

- Route: `/accounting/reports/balance-sheet`; API: `GET api/accounting/reports/balance-sheet?asOfDate=2026-11-26` (optional `fiscalYearId`). Uses the existing journal view permission.
- Reads posted ledger lines cumulatively through the selected date, including opening, closing and posted reversal entries. Fiscal year selection validates the date, not the beginning of the ledger range. The current chart of accounts and effective financial classifications are used.
- Direct asset balances are debit minus credit; liabilities, equity and nominal account balances are credit minus debit. This handles contra accounts without assuming that their normal balance determines the sign. Nominal account residual balances are included once in equity as unclosed profit/loss; after closing, their net amount is zero and retained earnings already include the result. The income statement's exclusion of closing entries is intentionally NOT used here.
- Totals come from direct balances, not from summing visible rows and subtotals. Missing asset/liability classifications are retained in separate groups, and working capital is not presented as reliable when nonzero unclassified balances exist. Balance status uses the base-currency difference before rounding.
- Four modes: side-by-side (default), detail, summary, comparison. A level limit rolls detail into same-category ancestor buckets where possible; a different category is never incorrectly merged just to satisfy a level. Search changes visible detail only. Print/PDF (browser dialog) and Excel export all rows for the applied mode, not just the current page or search. Comparison uses the selected currency's accounting rate at the current statement date for both snapshots, as a presentation conversion only. Historical classifications and source chart changes are not versioned by this report.
- Individual accounts open the account statement with the same cutoff date and currency (year start plus opening balance). Aggregated rows are not linked because a subtree may include other categories.
- No migration. Apply the earlier financial statement category migration if not already applied. The account editor's normal-balance behavior is not changed by this report.

## Verification

Run `dotnet build OAS.API/OAS.API.csproj` and `dotnet build OAS.Client/OAS.Client.csproj` with .NET 9. Run `dotnet test OAS.Tests/OAS.Tests.csproj --filter FullyQualifiedName~BalanceSheetTotalsTests`. With a disposable SQL Server test connection configured using `OAS_SALES_TEST_SQLSERVER`, run the existing `CustomerArBalancesSqlServerTests` fixture (it creates a separate randomly named test database). The added integration test checks as-of snapshots and posted nominal account balances.

Manual checks: compare asset, liability, equity and nominal signed balances against the trial balance through the same date; validate opening/closing and reversals across dates; check contra-assets; test loss, unclassified balances, year selection, search, pagination, all modes and currency conversion; print/export and compare amounts; ensure search and page selection never change financial totals.
