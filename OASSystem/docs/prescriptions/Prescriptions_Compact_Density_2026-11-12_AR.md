# تصغير أحجام واجهتي الوصفات البصرية — 12 نوفمبر 2026

## المطلوب

تعديل **قائمة الوصفات** و**إضافة وصفة جديدة** لتصبحا أقل ارتفاعًا وأكثر ملاءمة لشاشة 1366×768 مع بقاء الألوان المعتمدة ونفس التوزيع والتبويبات والمحتوى.

## ما تغير

تعديل تنسيقات الواجهتين فقط في:

`Shared/UiLib/wwwroot/css/features/prescriptions-approved.css`

أُضيفت قواعد *Compact density* في نهاية الملف، وهي محصورة داخل `.oas-rx-screen`، دون تعديل صفحات المحاسبة والمبيعات الأخرى أو الخدمات والعقود وقاعدة البيانات.

| العنصر | قبل | بعد |
|---|---:|---:|
| ارتفاع شريط العنوان | 83px | 60px |
| ارتفاع التبويب | 50px | 38px |
| الحد الأدنى لارتفاع البطاقات | 123px | 90px |
| حجم الرقم الرئيسي | 31px | 24px |
| الحد الأدنى لارتفاع شريط الفلاتر | 62px | 47px |
| ارتفاع حقل بيانات الوصفة | 44px | 35px |
| ارتفاع حقل قياس العين | 36px | 31px |
| ارتفاع ترويسة نموذج الإضافة | 76px | 56px |

كما تقلصت هوامش أقسام النموذج والتبويبات والبطاقات والجدول، وتقاربت عناوين الأقسام، وتقلصت أزرار الحفظ مع بقائها مقروءة. احتفظت بقواعد العرض المتجاوب وقابلية التمرير الأفقي للقياسات في المساحات الضيقة.

## تثبيت الألوان

احتُفظ بألوان الأزرق السماوي لرؤوس الجداول والتبويب النشط، والأصفر الشمسي للإجراء الرئيسي، والتدرجات الفاتحة للبطاقات، ولم تُغير متغيرات الثيم العامة.

## التحقق

- اجتاز الملف تحليل صياغة CSS باستخدام `tinycss2` دون أخطاء في بنية القواعد.
- بقي استيراد `prescriptions-approved.css` في نهاية `oas-ui-bundle.css` بعد التنسيقات العامة.
- لم تتغير ملفات Razor أو منطق الحفظ، لذا لم تُضف مخاطر جديدة خاصة بمترجم Razor.
- **لم يُشغّل .NET أو تُفحص الواجهة داخل Blazor في هذه البيئة؛** راجع ارتفاع المكونات فعليًا بعد دمج الملف.

## التثبيت

انسخ الملف إلى مساره المطابق، ثم حدّث المتصفح بـ `Ctrl+F5`. إعادة بناء الحل اختيارية لهذا التعديل لأن الملف CSS فقط؛ إذا لم تظهر التغييرات، أعد تشغيل تطبيق العميل وافحص طلب ملف CSS في أدوات المطور.
