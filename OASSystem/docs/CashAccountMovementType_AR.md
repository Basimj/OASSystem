# تصنيف حركة الصناديق

## التحديث
- `MovementType` في `dbo.tbl_CashAccounts`: ‏1 وارد فقط، ‏2 صادر فقط، ‏3 وارد وصادر.
- الصناديق القديمة والجديدة (ما لم يحدد المستخدم غير ذلك) تأخذ القيمة 3. لا تعدل القيود التاريخية.
- Migration: `20261128161500_AddCashAccountMovementType`.
- يرفض الخادم القيم خارج 1–3، ويعيد التحقق من اتجاه القبض/الصرف عند إنشاء سندات التسوية وعند ترحيل القيود النقدية. التحويلات الداخلية والعكس النظامي وتسويات الورديات وقيود الافتتاح والإقفال لا تخضع لقيد الاتجاه التشغيلي، لكنها تخضع لضوابطها الحالية.
- لا يسمح بتغيير نوع الحركة في وجود وردية مفتوحة أو قيد الإغلاق. تعريف الحسابات البنكية لم يتغير. الصندوق الافتراضي يبقى واحدًا لكل عملة؛ لا يتم اختياره من قوائم العمليات المخالفة لنوعه.
- فلتر التقرير يختار الصناديق بحسب تصنيفها الحالي، ويعرض حركاتها الفعلية بما فيها التحويلات والعكس؛ ليس فلترًا لاتجاه القيد التاريخي.

## أوامر التحديث (من مجلد OASSystem)
بعد أخذ نسخة احتياطية وضبط اتصال قاعدة البيانات الصحيحة:

```powershell
dotnet ef database update --project OAS.Infrastructure --startup-project OAS.API --context OasDbContext
dotnet build OAS.API/OAS.API.csproj
dotnet build OAS.Client/OAS.Client.csproj
dotnet test OAS.Tests/OAS.Tests.csproj --filter FullyQualifiedName~CashAccountMovementTypeTests
```

اختبار SQL Server المعزول الموجود في `CashShiftMovementSqlServerTests` يتطلب متغير البيئة `OAS_SALES_TEST_SQLSERVER` واتصالًا يسمح بإنشاء قاعدة اختبار مؤقتة وحذفها. لا تستخدم قاعدة الإنتاج في الاختبار.

## اختبار يدوي
1. أنشئ ثلاثة صناديق من عملة واحدة بنوع مختلف لكل منها (لا تجعل أكثر من صندوق افتراضيًا في العملة نفسها).
2. تحقق من ظهور صندوق الوارد وصندوق النوع المزدوج فقط في سند القبض، ومن ظهور صندوق الصادر والمزدوج في سند الصرف. كرر في المبيعات والمشتريات والمصروفات ورد المبالغ.
3. احفظ مسودة سند ثم غيّر نوع صندوقه (مع إغلاق ورديته)، وتأكد من رفض اعتماد/ترحيل العملية المخالفة.
4. نفذ تحويلًا من صندوق الوارد إلى صندوق الصادر مع توفر الرصيد والوردية المطلوبة؛ ثم تحقق من عكس العملية بضوابط النظام.
5. افتح وردية وحاول تغيير نوع الصندوق: يجب الرفض. أغلق الوردية ثم أعد المحاولة.
6. افتح تقرير الصناديق والبنوك واختر نوع الحركة، وتحقق من أن الحركات السابقة لا تختفي بسبب اتجاهها.

## حدود التحقق
أجريت مراجعة نصية للكود والملفات المعدلة، ولم أشغّل بناء .NET أو اختبارات SQL Server في بيئة التسليم لعدم وجود SDK أو اتصال قاعدة البيانات. استيراد Excel الحالي يبقى متوافقًا ويستخدم النوع الافتراضي عند إنشاء صندوق؛ لا يتضمن عمود اختيار النوع في هذه الحزمة.
