# Inventory V1 QA assets

This folder contains the manual QA plans produced while validating the OAS Inventory V1 UI.
The matching SQL verification and test-data scripts are under `scripts/inventory`.

Covered screens:
- Products
- Warehouses
- Inventory Balances
- Inventory Transactions
- Inventory Ledger
- Stock Counts

These files are documentation/test assets only and are not included in application runtime logic.
