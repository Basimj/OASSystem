# إصلاح صفحة طلبات العملاء — الأزرار وإغلاق قائمة الاختيار

**التاريخ:** 13 نوفمبر 2026

## المشكلة الأولى: لون نص «إضافة بند» و«إضافة نظارة»

كان الشريط `ui-sales-lines__toolbar` يطبق لونًا مستقلًا على عنصر `span` الداخلي، ولذلك لم يكن تغيير `color` في الزر كافيًا. أضيف محدد CSS يستهدف النص الداخلي والأيقونات مباشرة، باللون الأبيض `#FFFFFF` مع بقاء الخلفية الزرقاء والخط الأصفر السفلي دون تغيير الأبعاد.

## المشكلة الثانية: قائمة العملة تظل مفتوحة بعد الاختيار

الاعتماد على `popovertargetaction="hide"` وحده لم يغلق النافذة بشكل ثابت بعد تحديث نموذج Blazor. أضيفت دالة JavaScript صغيرة لإغلاق الـ popover صراحةً **قبل** إطلاق حدث `ValueChanged` وإعادة رسم النموذج، مع إبقاء الإغلاق الأصلي في HTML كآلية احتياطية.

تم تحسين `UiLookup` للاحتفاظ بنص العنصر المختار أثناء تحديث النموذج، مع علامة تحقق خضراء عند وجود قيمة، بحيث يرى المستخدم العملة أو العميل الذي اختاره بعد إغلاق القائمة. سلوك الاختيار الافتراضي غير المنبثق (`UsePopover=false`) لم يتغير.

## الملفات المعدّلة

- `Shared/UiLib/wwwroot/css/features/customer-orders-approved.css`
- `Shared/UiLib/Components/Inputs/UiLookup.razor`
- `Shared/UiLib/Components/Inputs/UiLookup.razor.css`
- `Shared/UiLib/wwwroot/js/oas-lookup-popover.js` **(ملف جديد)**

## التحقق

- نجح فحص JavaScript باستخدام `node --check` واختبار محدود لدالة الإغلاق.
- نجح تحليل صياغة ملفات CSS باستخدام `tinycss2` دون أخطاء.
- تم فحص أن ملفات ZIP سليمة وأن جميع الملفات الأصلية الأخرى لم تتغير.
- **لم يتم إجراء `dotnet build` أو تشغيل Blazor بقاعدة بيانات حقيقية**؛ يجب التحقق منهما في Visual Studio قبل اعتماد الإصلاح.

## تجربة القبول

1. نفّذ `Clean Solution` ثم `Rebuild Solution`، وشغّل `/sales/customer-orders` ثم `Ctrl + F5`.
2. افتح «طلب جديد». تأكد أن نص زرّي «إضافة بند» و«إضافة نظارة» وأيقونتيهما باللون الأبيض وأن الخط السفلي أصفر والخلفية زرقاء.
3. افتح اختيار العملة؛ اختر عملة. يجب أن **تغلق النافذة مباشرة** وتظهر العملة المختارة وعلامة التحقق في الحقل.
4. أعد فتح اختيار العملة واختر عملة ثانية، وجرّب أيضًا اختيار العميل والصنف.
5. تأكد من أن تغيير العملة ما زال يُحدّث السعر والملخص المالي وفق منطق النظام، وأن الحفظ يعمل.
